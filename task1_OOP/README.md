# Маршруты городского транспорта

Учебный проект по объектно-ориентированному программированию (вариант № 13, первая аттестация). Приложение моделирует остановки, маршруты городского транспорта и рейсы, формирует расписания по остановке и позволяет искать поездки без пересадки или с одной пересадкой.

## Требования

- Java Development Kit (JDK) 21
- Apache Maven

## Сборка и запуск

Откройте терминал в корневой папке проекта `task1_OOP` (там, где расположен файл `pom.xml`).

Соберите проект и выполните тесты:

```bash
mvn clean package
```

Запустите консольную демонстрацию:

```bash
java -cp target/classes model.Main
```

Программа выводит заранее созданные в `Main` данные; ввод с клавиатуры не требуется. Данные не загружаются из файлов или базы данных.

Для отдельного запуска тестов:

```bash
mvn test
```

Для проверки установленных версий инструментов можно выполнить `java -version` и `mvn -version`.

## Модель предметной области

Основные классы пакета `model`:

- `Stop` — остановка с идентификатором и названием (`record`).
- `RouteSegment` — остановка и длительность движения от неё до следующей остановки (`record`).
- `Route` — маршрут: номер, название, тип транспорта, упорядоченные сегменты и интервал движения. Позволяет рассчитывать время движения и проверять возможность поездки между остановками в нужном направлении.
- `Trip` — рейс по определённому маршруту с временем отправления и типом дня; вычисляет время прибытия на остановку, в том числе с учётом даты.
- `TransportType` — перечисление видов транспорта с характеристиками средней скорости и вместимости.
- `DayType` — тип дня (`WEEKDAY` или `WEEKEND`).

Сервисы пакета `service`:

- `TripGenerator` — формирование рейсов по заданному интервалу движения.
- `StopSchedule` — получение расписания остановки для типа дня или конкретной даты; `StopScheduleEntry` и `StopScheduleDateEntry` представляют строки расписания (`record`).
- `PathFinder` — интерфейс поиска маршрутов, реализованный классами `DirectPathFinder` (без пересадки) и `TransferPathFinder` (с одной пересадкой).
- `TransferRouteOption` — вариант маршрутов и остановки пересадки (`record`).
- `TransferJourney` — найденная поездка с двумя рейсами, индексами остановок, временем ожидания и общей длительностью (`record`).

Пакет `exception` содержит собственные исключения `TransportException`, `RouteNotFoundException` и `ScheduleNotFoundException`.

## Реализованные возможности

**Базовый уровень:**

- формирование расписания рейсов по остановке;
- расчёт времени прибытия на заданную остановку маршрута;
- получение интервала движения и возможность автоматической генерации рейсов с заданным интервалом;
- поиск маршрутов между двумя остановками без пересадки с учётом направления движения;
- расчёт общей длительности маршрута и времени между остановками.

**Повышенный уровень:**

- поиск поездки с одной пересадкой и проверка минимального времени пересадки на неё;
- выбор варианта с наименьшей общей длительностью поездки, включая ожидание пересадки;
- отдельные расписания для будних и выходных дней;
- поддержка кольцевых маршрутов с повторяющимися остановками и корректным определением направления движения и времени поездки.

При вычислениях используются типы `LocalTime`, `LocalDate`, `LocalDateTime` и `Duration` из `java.time`.

## Консольная демонстрация

Точка входа — `src/main/java/model/Main.java` (`model.Main`). Демонстрация создаёт остановки, маршруты и рейсы, выводит расписания, время прибытия, интервалы и продолжительность поездок. Также показаны поиск прямых маршрутов, поиск и выбор поездки с пересадкой, ситуация с недостаточным временем на пересадку, ночной рейс с переходом через полночь, обработка собственных исключений и полиморфизм интерфейса `PathFinder`.

## Тестирование

JUnit 5 используется для автоматических тестов. Тестовые классы находятся в `src/test/java/model` и `src/test/java/service` и проверяют модель и сервисы, включая граничные случаи и обработку ошибок.
